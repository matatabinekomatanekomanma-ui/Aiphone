# Aiphone (AI 전화 도우미)

**다른 언어:** [日本語](README.md) · [English](README.en.md) · [简体中文](README.zh-CN.md) · [繁體中文](README.zh-TW.md) · [Español](README.es.md)

Aiphone는 사용자가 전화 목적과 주요 내용을 미리 정리한 뒤, 사용자가 직접 발신한 전화에서 AI가 대화와 응대를 돕도록 하는 실험적인 Android 앱입니다. Gemini API를 사용한 양방향 음성 번역 기능도 실험적으로 구현되어 있습니다.

> **초기 개발 단계의 실험용 소프트웨어입니다.** UI와 사용성은 아직 충분히 다듬어지지 않았으며, 기기와 통화 앱에 따라 동작이 달라질 수 있습니다. 계약, 금전, 의료, 공공기관 업무 등 중요한 통화를 AI에만 맡기지 마세요.

## 주요 기능

- 발신 전에 통화 목적과 요점을 정리하고, 발신 통화 중 AI가 응대하도록 지원
- 상대방의 발화와 대화 흐름에 따라 AI가 응답하는 통화 세션
- Gemini Live를 이용한 양방향 음성 번역(원본 언어와 대상 언어 설정 가능)
- 개인 정보를 기기에 저장하고, AI가 특정 정보를 공개하기 전에 사용자 허가를 받도록 지원
- 영어, 중국어(간체/번체), 한국어, 스페인어 등 앱 UI 언어 변경

### 향후 계획

- 수신 전화 AI 응대
- 통화 녹음
- 통화 내용 텍스트 변환

이는 향후 계획이며 현재 버전에서 제공된다는 의미는 아닙니다. 이 README에서는 녹음 및 텍스트 변환을 구현 완료 기능으로 안내하지 않습니다.

## 비용

Aiphone 앱 자체에는 유료 요금제나 앱 내 구매가 없으며 앱 기능은 무료로 제공하는 것을 목표로 합니다. Gemini API는 무료 사용량 범위에서 이용하도록 설계되어 있으며 유료 전용 기능에 의존하지 않습니다.

다만 **Gemini API 무료 사용량, 모델 제공 여부 및 호출 제한은 Google의 정책에 따라 달라지며 영구 무료를 보장하지 않습니다.** API 키를 만들거나 사용하기 전에 최신 가격과 약관을 확인하세요.

- [Gemini API 키 만들기(Google AI Studio)](https://aistudio.google.com/app/apikey)
- [Gemini API 추가 서비스 약관](https://ai.google.dev/gemini-api/terms)

## 테스트 환경

- 테스트 기기: AQUOS sense6s (SH-RM19s)
- 테스트 OS: Android 13
- `minSdk`는 Android 11(API 30)이지만 모든 Android 11 이상 기기에서 테스트했거나 동작을 보장한다는 뜻은 아닙니다.

현재 실제 기기 테스트는 위 기기에서만 진행했습니다. 제조사의 오디오 처리, 통화 앱, OS 제한으로 인해 다른 기기에서는 다르게 동작할 수 있습니다.

## 필요 항목

1. **Gemini API 키**(직접 준비해야 합니다).
2. **priv-kit**을 통해 무선 디버깅으로 shell 권한을 얻기 위한 Android 개발자 옵션 설정.
3. 호환되는 Android 기기, 사용하는 통화 앱 및 기능에 필요한 Android 권한.

priv-kit은 Android 특권 프로세스를 시작하고 관리하는 라이브러리입니다. 이 앱은 무선 디버깅을 통해 shell 권한으로 실행되는 브리지에 연결합니다. 일반 앱보다 높은 권한이 필요하므로 이해하고 신뢰하는 기기와 네트워크에서만 권한을 부여하세요.

- [priv-kit 공식 저장소](https://github.com/priv-kit/priv-kit)

## 설정 개요

1. Android 개발자 옵션에서 '무선 디버깅'을 활성화합니다.
2. Aiphone 설정에서 priv-kit 설정 가이드를 열고 페어링 및 연결 절차를 따릅니다.
3. 직접 준비한 Gemini API 키를 앱에 입력합니다.
4. 개인 정보와 이번 통화의 목적, 전달·확인할 내용, AI가 스스로 판단해도 되는 범위를 입력합니다.
5. 필요한 권한을 허용하고 AI 응대를 사용할 발신 통화에서 기능을 활성화합니다.
6. 번역을 사용할 경우 번역 화면에서 자신의 언어와 상대방의 언어를 선택한 뒤 시작합니다.

설정 이름과 Android 화면은 기기 및 OS 버전에 따라 다를 수 있습니다. 연결에 실패하면 앱 내 가이드와 진단 정보를 확인하세요.

## 개인정보 및 안전

[개인정보 안내](PRIVACY.ko.md)를 읽어 주세요. 통화 음성과 관련 텍스트가 Gemini API로 전송될 수 있습니다. Google 무료 사용량의 약관에 따라 입력 및 생성 결과가 Google 서비스 개선에 사용되거나 사람이 검토할 수 있습니다. 개인 정보나 기밀 정보가 포함된 통화에 무료 사용량을 사용할 때 특히 주의하세요.

AI가 통화에 참여하고 있다는 사실을 숨기는 용도로 사용하지 마세요. 상대방에게 AI의 참여를 알리고, 음성 처리나 녹음에 필요한 동의를 받고, 개인 정보를 적법하게 처리하며 관련 법률과 서비스 약관을 확인하는 것은 사용자 책임입니다.

일부 VoIP 통화에서는 통화 방향을 확실히 판단하지 못할 수 있습니다. 안전을 위해 이 경우 AI 자동 시작을 건너뜁니다. 발신 통화인지 확인한 후 앱에서 수동으로 시작하세요.

## 빌드

1. 이 저장소를 clone하거나 다운로드합니다.
2. Android Studio에서 저장소 루트 디렉터리를 엽니다.
3. Gradle 동기화가 완료되면 `:app:assembleDebug`를 실행합니다.

빌드에는 Android Gradle Plugin, Kotlin, AndroidX, Material Components, OkHttp, priv-kit 등의 의존성을 네트워크로 다운로드할 수 있어야 합니다.

## 면책

소프트웨어는 어떠한 보증 없이 '있는 그대로' 제공됩니다. AI는 음성을 잘못 이해하거나 번역 또는 응답을 부정확하게 생성할 수 있습니다. 결과를 직접 확인하고 중요한 결정이나 동의를 감독 없이 AI에 전적으로 맡기지 마세요.
