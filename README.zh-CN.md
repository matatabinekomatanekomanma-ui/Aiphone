# Aiphone（AI 电话助手）

**其他语言：** [日本語](README.md) · [English](README.en.md) · [繁體中文](README.zh-TW.md) · [한국어](README.ko.md) · [Español](README.es.md)

Aiphone 是一款实验性的 Android 应用，旨在让用户预先整理电话目的和要点，再由 AI 协助处理用户主动拨出的电话。应用还试验性地实现了基于 Gemini API 的双向语音翻译。

> **本应用仍处于早期实验阶段。** UI 和易用性尚未完善。不同设备和通话应用上的行为可能不同。涉及合同、金钱、医疗、政府事务或其他重要决定时，请勿完全依赖 AI。

## 功能

- 拨号前整理通话目的和要点，并让 AI 在主动拨出的电话中应答。
- 根据对方发言和对话上下文生成 AI 回复的通话会话。
- 使用 Gemini Live 进行双向语音翻译，可设置源语言和目标语言。
- 在设备本地保存个人信息，并在 AI 透露指定信息前请求用户授权。
- 设置中的“录制通话音频”开启时（默认开启），将通话音频保存为 M4A 文件，存放在设备共享的 `Music/Aiphone/` 文件夹中。
- 支持切换应用界面语言，包括英语、简体中文、繁体中文、韩语和西班牙语。

录音包含对方的声音以及传到对方一侧的音频（包括 AI/翻译语音）。未使用 AI 或翻译时，也会录制您自己的声音。文件保存在设备共享的音乐文件夹中。

### 未来计划

- 由 AI 处理来电
- 自动转写并保存通话内容

通话录音已经实现。自动转写并归档通话内容仍是未来可能添加的功能。

## 所需条件

1. **Gemini API 密钥**（请自行申请）。
2. 通过 **priv-kit** 使用无线调试取得 shell 权限所需的 Android 开发者选项设置。
3. 兼容的 Android 设备、所使用的通话应用，以及相应功能需要的 Android 权限。

priv-kit 是用于启动和管理 Android 特权进程的库。本应用通过无线调试连接到以 shell 权限运行的桥接进程。其权限高于普通应用，请只在自己理解并信任的设备和网络上进行授权。

- [priv-kit 官方仓库](https://github.com/priv-kit/priv-kit)

## 设置概要

1. 在 Android 开发者选项中启用“无线调试”。
2. 从 Aiphone 的设置界面打开 priv-kit 设置指南，并按照步骤完成配对和连接。
3. 在应用中填写自行准备的 Gemini API 密钥。
4. 输入个人信息、此次通话目的、需要传达或确认的事项，以及 AI 可以自行决定的范围。
5. 授予必要权限，并为希望由 AI 协助处理的拨出电话启用功能。
6. 使用翻译功能时，请先在翻译界面选择自己的语言和对方的语言。

设置名称和 Android 界面会因设备和系统版本而异。若连接失败，请查看应用内的指南和诊断信息。

## 隐私与安全

请阅读[隐私说明](PRIVACY.zh-CN.md)。通话音频及相关文本可能会发送至 Gemini API。根据 Google 免费额度的条款，输入和生成的输出可能被用于改进 Google 服务，也可能由人工审核人员处理。对包含个人信息或机密信息的通话使用免费额度时应格外谨慎。

请勿用本应用隐瞒 AI 正在参与通话。用户需自行负责向通话对方说明 AI 的参与情况、取得音频处理或录音所需的同意、依法处理个人信息，并确认适用法律和服务条款。

对于某些 VoIP 通话，应用可能无法可靠判断通话方向。为确保安全，应用会跳过 AI 自动启动；请确认这是拨出电话后，再从应用中手动启动功能。

## 构建

1. 克隆或下载此仓库。
2. 使用 Android Studio 打开仓库根目录。
3. Gradle 同步完成后运行 `:app:assembleDebug`。

构建需要联网下载 Android Gradle Plugin、Kotlin、AndroidX、Material Components、OkHttp、priv-kit 等依赖。
