# Aiphone（AI電話アシスタント）

**他の言語：** [English](README.en.md) · [简体中文](README.zh-CN.md) · [繁體中文](README.zh-TW.md) · [한국어](README.ko.md) · [Español](README.es.md)

Aiphone は、電話で伝えたい内容をあらかじめ整理し、ユーザーが発信した通話で AI が会話・応対することを目指す Android アプリです。Gemini API を使った双方向の音声翻訳機能も試験的に実装しています。

> **開発初期の実験的なアプリです。** UI とユーザビリティはまだ十分に洗練されていません。端末や通話アプリによって動作しない場合があります。重要な連絡、契約、金銭、医療、行政手続きなどを AI だけに任せないでください。

## 主な機能

- 電話の用件・目的を事前に整理し、発信した通話で AI が応対する機能
- 相手の発話や会話の流れに応じて AI が応答するための通話セッション
- Gemini Live を使った双方向音声翻訳（翻訳元・翻訳先の言語を設定）
- 個人情報を端末内に登録し、AI が相手へ伝える前にユーザーの許可を取るための機能
- 「通話内容を録音する」が ON（初期設定）なら、通話音声を M4A で端末の `Music/Aiphone/` に保存する機能
- 英語、中国語（簡体字・繁体字）、韓国語、スペイン語などのアプリ UI 言語切り替え

録音には、相手の声と相手に届く側の音声（AI・翻訳の声を含む）が含まれます。AI・翻訳を使わない通話では、自分の声も録音します。録音ファイルは端末の共有「音楽」フォルダに保存されます。

### 今後追加したい機能

- 着信への AI 応対
- 通話内容の自動文字起こし・保存

通話録音は実装済みです。通話内容の文字起こしを自動的に記録・保存する機能は、今後の追加候補です。

## 料金について

Aiphone の機能は無料で、アプリ内課金や有料プランはありません。Gemini API は無料利用枠内での利用を想定し、有料専用機能を前提にしていません。

ただし、**Gemini API の無料枠・モデル提供・回数制限は Google 側の条件に依存し、永久に無料で使えることを保証するものではありません。** 利用条件によって扱いが変わる場合もあります。API キーを作成するときと利用前に、最新の料金・利用規約を確認してください。

- [Gemini API キーの作成（Google AI Studio）](https://aistudio.google.com/app/apikey)
- [Gemini API 追加利用規約（日本語）](https://ai.google.dev/gemini-api/terms?hl=ja)

## 動作確認環境

- 確認済み端末：AQUOS sense6s（SH-RM19s）
- 確認済み OS：Android 13
- アプリの `minSdk` は Android 11（API 30）です。ただし、Android 11 以降のすべての端末で動作することを確認したわけではありません。

現時点では上記端末でしか実機確認をしていません。メーカー独自の音声処理、通話アプリ、OS の制限により、他の端末では動作しない可能性があります。

## 必要なもの

1. **Gemini API キー**（利用者が自分で用意してください）
2. **priv-kit** を介してワイヤレスデバッグから shell 権限を取得するための Android 開発者向け設定
3. 対応する Android 端末、利用する通話アプリ、および必要な Android 権限

priv-kit は Android の特権プロセスを起動・管理するためのライブラリです。このアプリではワイヤレスデバッグを利用して shell 権限で動くブリッジに接続します。通常のアプリより強い権限を伴うため、接続・許可を行う端末とネットワークを理解したうえで利用してください。

- [priv-kit の公式リポジトリ](https://github.com/priv-kit/priv-kit)

## セットアップ概要

1. Android の開発者向けオプションで「ワイヤレスデバッグ」を有効にします。
2. アプリの設定画面から priv-kit 接続の設定ガイドを開き、画面の手順でペアリングと接続を行います。
3. 自分で用意した Gemini API キーをアプリに設定します。
4. 個人情報と、今回の通話の目的・伝えたいこと・確認したいこと・AI が判断してよい範囲などを入力します。
5. 必要な権限を許可し、AI 応対を使いたい発信通話で機能を有効にします。
6. 翻訳を使う場合は、翻訳タブで自分の言語と相手の言語を設定してから開始します。

設定名や Android の画面は端末・OS バージョンにより異なることがあります。接続に失敗した場合は、アプリ内の設定ガイドと診断表示を確認してください。

通話方向が `UNKNOWN` になった場合は、[VoIP 通話判定の診断ログ手順](VOIP_DIAGNOSTICS.md)を参照してください。必要に応じて Android の「使用状況へのアクセス」を許可すると、対応通話アプリの使用履歴イベントを診断ログに含められます（任意）。診断ログは音声本文・電話番号・API キーを記録しませんが、対応通話アプリのパッケージ名・UIDや利用時刻などが含まれることがあります。ログを共有する前に内容を確認してください。

## プライバシーと安全性

必ず [プライバシー説明](PRIVACY.md) を読んでください。通話音声や関連するテキストは Gemini API に送信されます。Google の無料利用枠では、入力・出力が Google のサービス改善に利用されたり、人間のレビュアーが確認したりする場合があります。機密情報や個人情報を含む通話に無料枠を使うことには特に注意してください。

相手に AI が応対していることを隠す用途を推奨しません。利用者は通話相手への説明、録音・音声処理の同意、個人情報の取り扱い、適用される法令やサービス規約の確認について責任を負います。

VoIP アプリでは通話方向を確実に判定できない場合があります。その場合は安全のため AI の自動開始を見送り、発信通話であることを確認したうえでアプリから手動で開始してください。

## ビルド

1. このリポジトリを clone またはダウンロードします。
2. Android Studio でルートフォルダを開きます。
3. Gradle の同期が完了したら `:app:assembleDebug` を実行します。

ビルドにはネットワーク経由で Android Gradle Plugin、Kotlin、AndroidX、Material Components、OkHttp、priv-kit などの依存関係を取得できる環境が必要です。
