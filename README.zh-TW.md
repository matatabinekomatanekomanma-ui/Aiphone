# Aiphone（AI 電話助理）

**其他語言：** [日本語](README.md) · [English](README.en.md) · [简体中文](README.zh-CN.md) · [한국어](README.ko.md) · [Español](README.es.md)

Aiphone 是一款實驗性的 Android 應用程式，目標是讓使用者事先整理電話目的與重點，再由 AI 協助處理使用者主動撥出的電話。應用程式也試驗性地實作了使用 Gemini API 的雙向語音翻譯。

> **本應用程式仍處於早期實驗階段。** UI 與易用性尚未完善。不同裝置與通話應用程式上的行為可能不同。涉及合約、金錢、醫療、政府事務或其他重要決定時，請勿完全依賴 AI。

## 功能

- 撥號前整理通話目的與重點，並讓 AI 在主動撥出的電話中應答。
- 根據對方發言與對話脈絡產生 AI 回應的通話工作階段。
- 使用 Gemini Live 進行雙向語音翻譯，可設定來源語言與目標語言。
- 在裝置本機儲存個人資訊，並在 AI 揭露指定資訊前請求使用者授權。
- 支援切換應用程式介面語言，包括英文、簡體中文、繁體中文、韓文與西班牙文。

但是，**Gemini API 的免費額度、模型供應和呼叫限制由 Google 決定，無法保證永久免費。** 建立或使用 API 金鑰前，請確認最新價格與服務條款。

## 測試環境

- 已測試裝置：AQUOS sense6s（SH-RM19s）
- 已測試系統：Android 13
- `minSdk` 為 Android 11（API 30），但這不代表所有 Android 11 以上裝置都已測試或保證可用。

目前只在上述裝置上進行過實機測試。廠商音訊處理、通話應用程式及作業系統限制都可能導致其他裝置上的行為不同。

## 必要條件

1. **Gemini API 金鑰**（請自行申請）。
2. 透過 **priv-kit** 使用無線偵錯取得 shell 權限所需的 Android 開發人員選項設定。
3. 相容的 Android 裝置、使用中的通話應用程式，以及功能所需的 Android 權限。

priv-kit 是用來啟動與管理 Android 特權程序的程式庫。本應用程式透過無線偵錯連線至以 shell 權限執行的橋接程序。它具有比一般應用程式更高的權限，請只在自己理解並信任的裝置與網路上授權。

- [priv-kit 官方儲存庫](https://github.com/priv-kit/priv-kit)

## 設定概要

1. 在 Android 開發人員選項中啟用「無線偵錯」。
2. 從 Aiphone 的設定畫面開啟 priv-kit 設定指南，並依照步驟完成配對與連線。
3. 在應用程式中輸入自行準備的 Gemini API 金鑰。
4. 輸入個人資訊、這次通話的目的、需要傳達或確認的事項，以及 AI 可以自行判斷的範圍。
5. 授予必要權限，並為希望由 AI 協助處理的撥出電話啟用功能。
6. 使用翻譯時，請先在翻譯頁面選擇自己的語言與對方的語言。

設定名稱與 Android 畫面可能因裝置及系統版本而異。若連線失敗，請查看應用程式內的指南與診斷資訊。

## 隱私與安全

請閱讀[隱私說明](PRIVACY.zh-TW.md)。通話音訊及相關文字可能會傳送至 Gemini API。依據 Google 免費額度的條款，輸入與產生的輸出可能用於改善 Google 服務，也可能由人工審查人員處理。若通話包含個人資訊或機密資訊，使用免費額度時應特別謹慎。

請勿利用本應用程式隱瞞 AI 正在參與通話。使用者須自行負責向通話對方說明 AI 的參與、取得音訊處理或錄音所需的同意、依法處理個人資訊，並確認適用法律與服務條款。

部分 VoIP 通話可能無法可靠判斷通話方向。為了安全，應用程式會略過 AI 自動啟動；請確認這是撥出電話後，再從應用程式手動啟動功能。

## 建置

1. Clone 或下載此儲存庫。
2. 使用 Android Studio 開啟儲存庫根目錄。
3. Gradle 同步完成後執行 `:app:assembleDebug`。

建置需要透過網路下載 Android Gradle Plugin、Kotlin、AndroidX、Material Components、OkHttp、priv-kit 等相依套件。
